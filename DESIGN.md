## 1. Global rules

| Rule | Value |
|---|---|
| Starting cash / lives | $650 / 100 |
| Simulation step | 60 Hz fixed step; speeds 1x / 2x / 3x; pause |
| World | 1200 x 900 logical px; track half-width 22 px; base enemy speed (1.0x) = 55 px/s |
| Sell refund | 70% of base cost + all purchased upgrades (rounded down) |
| Wave bonus | $100 + wave number, plus Perplexity research income |
| Reward scale | waves 1-40: 100%, 41-60: 70%, 61-80: 40%, 81-100: 20% of the listed reward |
| HP scale | 1.0 to wave 40, then +0.02/wave to 1.4 (w60), +0.06/wave to 2.6 (w80), +0.17/wave to 6.0 (w100); applied to every enemy incl. bosses and children |
| Speed scale | 1.0 to wave 80, then +1.5%/wave (1.3 at wave 100) |
| Regrow | +1 HP (x HP scale) every 2 s up to max HP; inherited by all children |
| Camo | untargetable without detection unless Revealed; inherited by all children; Lockheed Martin is innately camo |
| Fortified | max HP x2 (and armour visuals); inherited only by children of bosses; Qwen can strip it from non-bosses |
| Damage formula | `(dmg + stacks) * mult * (1 + bonuses)` -> type resistance (0 = immune unless the hit ignores resistance) -> `x (1 - armour x (1 - armourPierce))` -> BFB weak-hit halving -> Heap shield halving -> `x (1 + marked)` -> `+ min(cap, pct x maxHP)` |
| Armour break | status reduces armour fraction (max of applied values) for its duration |
| Knockback budget | per enemy, pushes from attacks are capped per second at 40% (bosses 25%) of the enemy's unslowed movement, so stacked pushers can never hold an enemy in place; ability blasts ignore the cap |
| Rewards | each body pays its own reward exactly once when destroyed; leaks pay nothing; no double payment on splits |
| Lives | leaked enemy removes its listed lives (a leaking Bucket Sort also leaks everything it stored); 0 lives = defeat |
| Victory | destroying Palantir's body on wave 100 (5 s defeat sequence, then victory screen) |
| Targeting | First (closest to exit), Last, Strongest (most HP), Weakest, Closest (to tower); Bellarmine Student + AI uses Auto: camo > bosses > strongest |
| Line of sight | only The Legacy Monolith's server chassis block it |

## 2. Towers

All 20 towers have one base form and **four** purchasable upgrades (five states, tier 0-4). This deviates from the
master spec's "exactly 3 upgrades" rule (section 4) at the user's explicit request. Upgrade names are the real model
lineups (e.g. upgrading Claude buys "Claude Sonnet 5.5"); the effect text is the mechanic. The 4th upgrade is an
expensive superclass form that changes how the tower plays. Displayed tower names stay the family name.

## 7. Difficulty Growth

Four selectable modes (`lindefense.sim.Difficulty`; pick on the map-select screen or `-Dlindefense.difficulty=O1|ON|ON2|ONN`).
All knobs are relative multipliers on top of the base game. Ramped knobs use `base + (final - base) * growth(wave)` where
growth is 0 (O(1)), `w/100` (O(N)), `(w/100)^2` (O(N^2)) or `(e^(6w/100) - 1)/(e^6 - 1)` (O(N^N)).

| Knob | O(1) | O(N) | O(N^2) | O(N^N) |
|---|---|---|---|---|
| Subtitle | Constant (current) | Linear (Normal) | Quadratic (Hard) | Super-exponential (Impossible) |
| Growth curve | flat | linear | quadratic | superexp |
| Enemy HP x (wave 1 -> 100) | 1 -> 1 | 1.1 -> 1.5 | 1.2 -> 2.2 | 1.3 -> 3 |
| Enemy count x (wave 1 -> 100) | 1 -> 1 | 1.1 -> 1.4 | 1.2 -> 2.3 | 1.3 -> 2.4 |
| Tower damage x (flat) | 1 | 0.92 | 0.86 | 0.75 |
| Income x (kill rewards + wave bonus, flat) | 1 | 0.8 | 0.6 | 0.5 |
| Elite chance per spawn (wave 1 -> 100) | - | - | 3% -> 60% | 5% -> 60% |
| Elite extra modifiers | - | - | 1 of Camo/Regrow/Fortified | 2 of Camo/Regrow/Fortified |
| Elite promotion to tougher type | - | - | 35% of elites | 50% of elites |
| Starting cash x / lives x | 1 / 1 | 1 / 1 | 1 / 1 | 2 / 1 |
| Extra bosses | - | - | - | 14 groups (below) |

Elites: each non-boss spawn is an elite with the chance above (deterministic from game seed + wave + group). Elites are split into their own
spawn group with extra random modifiers and, for some, a promotion to a tougher type (e.g. Quick Sort -> Heap Sort). Enemy counts are
rounded stochastically (deterministic per seed, minimum 1) and spawn intervals shrink by `1 + 0.5 (countMult - 1)`. Bosses already in the wave are never multiplied.
Palantir does not receive the ramped HP multiplier: its HP is multiplied by `towerDamage x (1 + 0.03 x tier)` so the final fight takes about as long as in O(1) (a DPS check, not a wall).
Kill rewards and the wave bonus are both scaled by the income multiplier (research-tower income is not). Any mode can be tried with `-Dlindefense.difficulty=O1|ON|ON2|ONN`.

Tower stats are expected to change, so re-run `AutoPlayer` with `-Dbot.difficulty=...` after any rebalance; the multipliers are relative, so the tier spacing should hold.

O(N^N) is tuned so a near-optimal defence wins 9 of 12 map/seed runs; every loss is on The Singularity Core in waves 88-98.
A flat 3x enemy HP from wave 1 (with half income) was tried and is unwinnable (the bot falls by wave 10-13), so HP ramps to 3x instead
and O(N^N) starts with double cash. Capped/random-bot rows were not re-run after the income retune.
