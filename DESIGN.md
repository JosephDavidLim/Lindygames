## 1. Global rules

| Rule | Value |
|---|---|
| Starting cash / lives | $650 / 100 |
| Simulation step | 60 Hz fixed step; speeds 1x / 2x / 3x; pause |
| World | 1200 x 900 logical px; track half-width 22 px; base enemy speed (1.0x) = 60 px/s |
| Sell refund | 70% of base cost + all purchased upgrades (rounded down) |
| Wave bonus | $1,178 after wave 1 (formula: 300 + 900 x max(0, 1 - wave/40), falling linearly to a flat $300 from wave 40 on; was $100 + wave), plus Perplexity round income |
| Reward scale | waves 1-20: 3x, 21-60: 3x, 61-80: 4x, 81-100: 1.6x the listed reward (the tower spec made towers several times dearer, so the original 1.0 / 0.7 / 0.4 / 0.2 taper could not pay for them; late bosses pay huge child cascades, hence the low final tier) |
| HP scale (every enemy, bosses included) | 1.0 to wave 60, then +0.005/wave to 1.1 (w80), +0.01/wave to 1.3 (w100); never decreases (was a ramp to 6.0 at wave 100 plus a separate boss curve) |
| Speed scale | 1.0 to wave 80, then +1.5%/wave (1.3 at wave 100) |
| Regrow | +1 HP (x HP scale) every 2 s up to max HP; inherited by all children |
| Camo | untargetable without detection unless Revealed; inherited by all children; Lockheed Martin is innately camo |
| Fortified | max HP x2 (and armour visuals); inherited only by children of bosses; Qwen's ability can strip it from airships |
| Damage types | SHARP cannot damage Lead-type; BLUNT/KINETIC x2 vs Ceramic-type; ENERGY plain; EXPLOSIVE splashes and cannot damage Camo unless the source has detection; SONIC x2 vs Ceramic-type and 20 px knockback on Lead-type; MAGIC hurts everything; GRAVITY slows on hit |
| Lead-type | Heap Sort and Lockheed Martin (whole body) and Radix Sort in its armoured phases (HP at or below 6 of its 8 layers) |
| Ceramic-type | the outer layer of Merge Sort, Quick Sort and TimSort, i.e. the body that releases children (Merge Run / Quick Partition are not Ceramic) |
| MOAB-class | any of the 5 bosses |
| Damage formula | `(dmg + extra + buffed flat dmg + flat bonuses) * map mult * (1 + % bonuses) * type & situation multipliers` -> immunities (Sharp vs Lead, Explosive vs undetected Camo) -> `x (1 - armour x (1 - armourPierce))` -> BFB weak-hit halving -> Heap shield halving -> `x (1 + % mark) + flat mark` -> `+ min(cap, pct x maxHP)`; Frozen enemies take x2, Fortified enemies take x2 while Armor Cracked |
| Status effects | SLOW: strongest applies, never stacks, bosses get 1/3 of any slow. STUN/FREEZE: bosses immune unless the tower says otherwise. MARKED: flat (+N) and percent (+X%) marks, strongest of each kind applies. KNOCKBACK: along the waypoint path only, bosses immune unless stated. BURN: refreshes, never stacks. ARMOR CRACK: removes Lead immunity and the Fortified HP bonus is ignored (modelled as x2 damage vs Fortified) |
| Buff stacking | same source tower type never stacks (highest wins); different types add. Caps: +100% attack speed, +10 pierce, +5 flat damage |
| Camo detection | built-in: Bellarmine Student + AI, Grok, Perplexity; gained at U2: Gemini, Llama; any tower within Perplexity's radius; every tower while a Perplexity U1+ exists |
| Heroes | only one copy of each hero may be placed |
| Abilities | usable from placement, start at 50% cooldown, count down in game time (so they speed up with fast-forward) |
| Knockback budget | per enemy, pushes from attacks are capped per second at 40% (bosses 25%) of the enemy's unslowed movement, so stacked pushers can never hold an enemy in place; ability blasts and scheduled events ignore the cap |
| Rewards | each body pays its own reward exactly once when destroyed; leaks pay nothing; no double payment on splits |
| Lives | leaked enemy removes its listed lives (a leaking Bucket Sort also leaks everything it stored); 0 lives = defeat |
| Victory | destroying Palantir's body on wave 100 (5 s defeat sequence, then victory screen) |
| Targeting | First (closest to exit), Last, Strongest (most HP), Weakest, Closest (to tower); Densest Cluster (Grok U2+): the enemy with the most other enemies within 60 px, ties go to First |
| Line of sight | only The Legacy Monolith's server chassis block it |

## 2. Towers

All 20 towers have one base form and **exactly three** purchasable upgrades (four states, tier 0-3), bought in order,
plus one ability. The displayed name is the family name and the spec's nickname is the subtitle. Tier labels are model
names in increasing order of model intelligence (heroes use their own tier names); the upgrade mechanics and costs follow
the spec's slot order. Source of truth for every number: `lindefense/tower/data/*.java`.

## 7. Difficulty Growth

Four selectable modes (`lindefense.sim.Difficulty`; pick on the map-select screen or `-Dlindefense.difficulty=O1|ON|ON2|ONN`).
All knobs are relative multipliers on top of the base game. Ramped knobs use `base + (final - base) * growth(wave)` where
growth is 0 (O(1)), `w/100` (O(N)), `(w/100)^2` (O(N^2)) or `(e^(6w/100) - 1)/(e^6 - 1)` (O(N^N)).

| Knob | O(1) | O(N) | O(N^2) | O(N^N) |
|---|---|---|---|---|
| Subtitle | Constant (current) | Linear (Normal) | Quadratic (Hard) | Super-exponential (Impossible) |
| Growth curve | flat | linear | quadratic | superexp |
| Enemy HP x (wave 1 -> 100) | 1 -> 1 | 1.1 -> 1.5 | 1.25 -> 3.1 | 1.3 -> 3.3 |
| Enemy count x (wave 1 -> 100) | 1 -> 1 | 1.1 -> 1.4 | 1.25 -> 2.4 | 1.3 -> 2.5 |
| Tower damage x (flat) | 1 | 0.92 | 0.84 | 0.75 |
| Income x (kill rewards + wave bonus, flat) | 1 | 0.8 | 0.56 | 0.5 |
| Elite chance per spawn (wave 1 -> 100) | - | - | 3% -> 80% | 5% -> 80% |
| Elite extra modifiers | - | - | 2 of Camo/Regrow/Fortified | 2 of Camo/Regrow/Fortified |
| Elite promotion to tougher type | - | - | 50% of elites | 50% of elites |
| Starting cash x / lives x | 1 / 1 | 1 / 1 | 1 / 1 | 2 / 1 |
| Extra bosses | - | - | - | 10 groups (below) |

Elites: each non-boss spawn is an elite with the chance above (deterministic from game seed + wave + group). Elites are split into their own
spawn group with extra random modifiers and, for some, a promotion to a tougher type (e.g. Quick Sort -> Heap Sort). Enemy counts are
rounded stochastically (deterministic per seed, minimum 1) and spawn intervals shrink by `1 + 0.5 (countMult - 1)`. Bosses already in the wave are never multiplied.
Palantir does not receive the ramped HP multiplier: its HP is multiplied by `towerDamage x (1 + 0.03 x tier)` so the final fight takes about as long as in O(1) (a DPS check, not a wall).
Kill rewards and the wave bonus are both scaled by the income multiplier (research-tower income is not). Any mode can be tried with `-Dlindefense.difficulty=O1|ON|ON2|ONN`.
